This project uses AGENTS.md as the source of truth for AI assistant behavior.

See ./AGENTS.md for full instructions on how to assist with this challenge.

## Source of Truth
- Architecture: Vanilla HTML + CSS (Tailwind v4 CDN) + Vanilla JS
- Build: No build step — static files served directly
- Test: Open `index.html` in browser or serve via Live Server on port 5500

## Project Structure
- `index.html` — Markup and Tailwind v4 CDN script tag
- `styles.css` — All styling via Tailwind @theme + @apply
- `script.js` — Calculator logic, keyboard input, theme switching
- `design/` — Design references (3 themes × desktop/mobile/active)
- `images/` — Favicon
